    How This Dashboard Gets Its Tasks

    The tasks are no longer written inside the page. The dashboard asks a backend API for them, and the backend answers with JSON.

    1. Intern DashboardThe page you are on
    2. JavaScript fetch()Sends the request
    3. REST API/api/tasks
    4. Node.js + ExpressThe backend server
    5. Task datatasks.json
    TechBridge Task Management API endpoints
    MethodEndpointPurposeUsed by this dashboard for
    GET/api/tasksGet all tasksLoading the task cards and the progress numbers
    GET/api/tasks/:idGet one taskThe View Task popup
    PUT/api/tasks/:idUpdate a task's statusMark as Completed, Start Task and Undo
    GET/api/healthCheck that the backend is runningThe Backend Status indicator
    POST/api/tasks/resetRestore the original tasksThe Reset task data button
    POST/api/tasksAdd a new task (optional)Not used on this page yet
    DELETE/api/tasks/:idDelete a task (optional)Not used on this page yet

    GET asks for information. PUT updates information that already exists. When the server cannot find a task it answers 404, and when the request is wrong it answers 400 with a short message.
